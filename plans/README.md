# Plans

Ephemeral planning documents for multi-session AI development.

This directory contains working documents used by AI agents to maintain
continuity across development sessions. Documents here are transient by
nature — they capture current thinking, task breakdowns, and session
context that may become stale as work progresses.

Use this `plans/` directory for short-lived, session-specific planning artifacts.
Longer-lived, higher-level planning lives in [`planning/plan.md`](../planning/plan.md),
which should remain the canonical, durable plan across sessions.
Feel free to delete or regenerate any file in this directory at any time.
